# Инструкция по развертыванию сайта Dopefolio на Ubuntu

Этот документ описывает шаги, необходимые для развертывания этого статического сайта на сервере с Nginx.

## 1. Подготовка сервера

Убедитесь, что на сервере установлен Nginx. Если нет, установите его:
```bash
sudo apt update
sudo apt install nginx
